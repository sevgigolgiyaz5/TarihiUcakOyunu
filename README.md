

\# Tarihi Uçak Oyunu



Unity 6 kullanılarak geliştirilen tarihi uçak oyunu projesidir.



\## Özellikler



\- Tarihi uçak 3D modeli

\- Pervane dönüş animasyonu

\- A ve D tuşları ile sağa-sola hareket

\- E tuşu ile ileri hareket

\- Z tuşu ile geri hareket

\- Rota02 oyun sahnesi



\## Kullanılan Teknolojiler



\- Unity 6

\- C#

\- Blender

\- Git / GitHub



\## Kontroller



\- A: Sola hareket

\- D: Sağa hareket

\- E: İleri hareket

\- Z: Geri hareket
